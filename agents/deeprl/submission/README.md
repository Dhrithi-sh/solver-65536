# P6 submission documents

P6_results.md describes the experiments and the separate handoff package.

The graphs and plotting script are included here. The inputs, training logs,
model checkpoints and source archive are in P6_Final_Submission.zip, shared
separately in accordance with the repository instructions.

To regenerate the graphs, run make_results.py from the extracted handoff folder,
where inputs/ is available.

The experiment source snapshot is commit 65afb11. Later documentation commits
do not represent retraining or new evaluation runs.
